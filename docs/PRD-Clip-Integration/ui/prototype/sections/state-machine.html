Priority Stack

The playout engine's decision hierarchy when re-evaluating after state changes:

P1 Live Routine Camera detects routine → switch to camera (clips are never interrupted except by Force Camera)
P2 Queued Clips Clips in queue → play next clip
P3 Fallback/Gap Fill Cycle through configured fallback sequence
