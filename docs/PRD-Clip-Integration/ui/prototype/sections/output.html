Mode Parameter Architecture
§4
?mode=clip
  • Video playback + overlay
  • Score reveal timing
  • REPLAY badge
  • Dual <video> elements
  • Writes clipStatus to Firebase
?mode=live
  • LIVE badge overlay
  • Score graphics
  • Animated backgrounds
  • Fallback overlays
  • No video elements
?mode=preview
  • Same as mode=clip
  • No Firebase writes
  • Producer testing only

Stall Detection & Recovery
§4
Stall Timeline
0s
waiting event fires
8s
Write { status: 'stalled' } to Firebase
13s
Skip to next clip + write { status: 'error', errorCode: 'STALL_TIMEOUT' }
Recovery
If playing fires before 8s:
Timer resets, no stall logged
If resumes between 8-13s:
Stall logged but playback continues
If still stalled at 13s:
Skip clip, log error, advance queue
