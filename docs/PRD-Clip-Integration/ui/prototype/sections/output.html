Write-Back Behavior

Heartbeat System Stale Player Detection
Heartbeat Mechanism
Interval — Every 2 seconds while clip is active
Firebase path — competitions/{compId}/clipPlayback/heartbeat
Value — Unix timestamp (Date.now())
Coordinator checks — If heartbeat > 10s old, player is stale
Stale Player Handling
Stale Detected
Coordinator marks player as disconnected, may auto-advance queue
Recovery
If player reconnects, resumes from last known position
Implementation
