Task 1: Debounce Iframe Preview URL Updates PASS

PRD Issue: #18

Files: show-controller/src/components/playout/WhoToWatchEditor.jsx

Problem: Every slider onChange rebuilt the overlay URL via useMemo, changing the iframe src and causing the entire overlay page to reload on each tick.

Fix: Added debounced version of overlay URL using useEffect + setTimeout (300ms) pattern.

Result: Sliders update in real-time with labels showing current values. Iframe preview only reloads after 300ms of inactivity. No lag or jank observed during slider interaction.

Card Adjustments panel expanded showing Name size (64px), Headline size (28px), Body size (30px) sliders. Slider labels update immediately while iframe debounces.

Task 3: Remove useEffect Sync Loop Causing Double-Renders PASS

PRD Issue: #21

Files: show-controller/src/components/playout/WhoToWatchEditor.jsx

Problem: useEffect([whoToWatch]) reset internal config state on every prop change. Since the parent creates a new object reference on every slider tick, this fired unnecessarily causing a double-render cycle.

Fix: Guarded useEffect with JSON comparison so it only resets when prop values actually differ from current config.

Result: No jank or double-render artifacts observed during slider interaction. Component responds smoothly to rapid slider changes.

Evidence: Same screenshot as Task 1 demonstrates smooth slider interaction without jank.
