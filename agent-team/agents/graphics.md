# Role: graphics

You change what OBS renders: `output.html`, `overlays/*.html`, `overlays/theme-loader.js`, `overlays/theme-overrides.css`, and the stage engine under `stage/` (engine, skeletons, blocks, per-graphic manifests). The registry files (`stage/graphics-registry.json`, `show-controller/src/lib/graphicsRegistry.generated.js`) are generated by `scripts/buildGraphicsRegistry.js`: never edit them by hand, run `cd show-controller && npm run prebuild`.

## Where to look first
- `docs/system-map/graphics-rendering.md`, `themes.md`, `sponsors.md`: every Firebase path, URL mode, and known gap for your engine.
- `docs/OPS-MANUAL.md`: "Stage Engine", "Unified Theme System", "Per-Graphic Overrides", "Live-Mode Override System".
- An existing graphic of the same category is the pattern to copy: a leaderboard manifest for a new card, `overlays/event-bar.html` for a new lower third.

## Rules that bite
- Every themed property uses the full 3-layer cascade `var(--{graphicId}-x, var(--meet-x, fallback))`, including the image, fit, position, and opacity variables, not only colors.
- Per-team graphics: strip the team number before registry lookups.
- The header-bar logo priority and background-image cascade are in the ops manual; do not invent a fourth layer.
- Sponsors come from `themes/{id}/sponsors` when a theme is active.
- `theme-loader.js` exposes `window.themeReady`; render after it resolves.

## How to verify (before you claim anything)
- Stage graphics: `stage/stage.html?preview=full&skeleton=full-screen-card&block=header-bar,leaderboard-table` renders sample data with no Firebase. Standalone: `stage/stage.html?comp={TEST_COMP_ID}&graphic={id}&theme={themeId}`.
- output.html and overlays: `output.html?graphic={id}&meetTheme={themeId}&debug=theme` and `overlays/{id}.html?meetTheme=...&debug=theme`. The debug panel shows which cascade layer each variable came from.
- These are static files. Ask `searcher` how local dev serves the repo root (vite config, a static route, or `file://`) before assuming a URL; the Theme Editor preview iframe is the reference path.
- Screenshot with Playwright at 1920x1080, save under `docs/verification/<TICKET>/`, read it back. A blank card, a missing logo, or fallback grey where a theme color belongs is a FAIL.
